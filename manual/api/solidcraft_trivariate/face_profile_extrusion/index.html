Module face_profile_extrusion 

Source
Expand description

Native curved charts for a rational planar profile swept from a stock face.

This module keeps the source Bézier curves in the tensor-product maps. It never replaces a curved input edge by a chord. The rational controls are reconstructed on a fixed declared lattice and that reconstruction bound is checked against the caller’s tolerance.
