Module constrained_elasticity 

Source
Expand description

Matrix-free solution of elasticity with exact affine scalar constraints.

The three components use independent Lift maps. The reduced system is applied as C^T K C and its right hand side is C^T(f-Kg), without forming a dense constraint matrix or a dense reduced stiffness matrix.
