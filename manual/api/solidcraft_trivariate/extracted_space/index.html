Module extracted_space 

Source
Expand description

Variable-size rational tensor-extracted elements and native elasticity.

Axis extraction matrices use Bernstein rows and local spline-function columns. Tensor products use the local ordering (i * n_v + j) * n_w + k. Geometry and field evaluation are kept separate at the public sample boundary, so a compact parent geometry can be integrated with a distinct extracted field space.
