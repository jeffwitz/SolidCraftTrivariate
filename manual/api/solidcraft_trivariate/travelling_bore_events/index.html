Module travelling_bore_events 

Source
Expand description

Analytic event and boundary-measure semantics for a translating circular bore.

The fixed body is the 20×20×8 mm plate with a blind rectangular pocket [-6,-2]×[-4,4] mm over z=[4,8] mm. A radius-2 mm vertical bore is centered at (c,0). The integer input is c in micrometres. All event classification uses integer comparisons; transcendental measures are reported as f64 evaluations of the exact circular-segment formulae below.

This module describes the ideal physical set and its analytic measures. It does not claim that a particular block decomposition represents every event. At an exact tangency the physical volume remains differentiable, but the representation signature changes and a representation jet is absent.
