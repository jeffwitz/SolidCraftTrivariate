Module axial_boolean 

Source
Expand description

Regularized booleans for products of one fixed G2 section and axial intervals.

The operation is performed on open axial cells between sorted interval bounds. Selected cells are retained as separate layers, including at a coplanar union contact; their common caps are represented as internal faces in the returned incidence. Cross-section intersections are outside scope.
