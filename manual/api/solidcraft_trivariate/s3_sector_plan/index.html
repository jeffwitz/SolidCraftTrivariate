Exact local cuts for the left wing of an S3 radial sector.

This module certifies only the supplied sector rows. In particular, it does not establish that the pocket’s far X limit remains inside the bore void; that predicate must be checked globally by the caller.

certify_xmax_void
Conservatively attest that pocket_xmax lies inside the simple S2 bore on the requested ordinate band. The caller must supply every right-wing source row pair for that band, after validating the simple-hole S2 topology. Each outer row must lie on the same stock xmax side; each inner row must be strictly to the right of the pocket limit. Monotone row intervals must cover the full band, and every band endpoint crossing must have an exact simple rational certificate.
