Module mapped_cut_propagation

Expand description

Exact closure of isoparametric cuts over oriented tensor-product interfaces.

A cut is represented by a rational parameter on one block axis. On every incident complete face, its parameter is transported through the declared axis permutation and reversal. The module refuses a crossing that is not declared isoparametric, and checks the full child count before allocation.
