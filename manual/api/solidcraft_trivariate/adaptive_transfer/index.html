Module adaptive_transfer 

Source
Expand description

Exact prolongation between nested dyadic adaptive Q2 spaces.

Each output row maps unconstrained source lift masters to one target lift master. This transfer does not include essential boundary conditions; a mechanical solver can transfer a complete xyz field and re-extract its own boundary-constrained reduced vector.
