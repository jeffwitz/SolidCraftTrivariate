Fitted crossed-tool bending

The fitted control uses the same physical union, clamp, traction and material as Crossed-tool partial-interface mechanics. Along the inclined wing the core meets only part of each wing-facing chart. Fitting the core to the two wing faces produces 22 charts with full interface traces. This gives a mechanical control for the ten-chart partial-interface calculation. The source geometry for the measured comparison is the recorded S2 union with a 3 mm rise over a 100 mm length.

Field construction

Each integration cell carries a rational displacement field of degree (3,2,2). A full chart interface shares trace coefficients. Within each chart, uniform subdivision in directions v and w supports two field choices:

  • C0 identifies trace values at each new subdivision.

  • C1 also identifies the parametric derivative across each new subdivision. If the two spans have the same parameter length and the same degree, the last interior, seam and first interior homogeneous controls satisfy \(H_L + H_R = 2 H_M\). The corresponding field relation is \(2 w_M d_M = w_L d_L + w_R d_R\), where \(w\) is a geometry weight and \(d\) is a displacement coefficient. The native signed lift applies these relations to the shared elasticity operator. The 22 original chart interfaces retain their shared value traces.

Reproduce the comparison

cargo build --release --locked --offline
cli=target/release/solidcraft-trivariate
mkdir -p build
"$cli" crossed-boolean tests/jobs/crossed_partial_rise3.recipe.json union build/inclined-cross.json
"$cli" conforming-bending build/inclined-cross.json 2 2 8 C0 build/fitted-c0.json
"$cli" conforming-bending build/inclined-cross.json 3 3 8 C1 build/fitted-c1.json
