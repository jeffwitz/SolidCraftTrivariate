SolidCraft Trivariate

SolidCraft Trivariate builds solids from sketch and feature recipes. Its Rust kernel represents material with rational volume maps. You can inspect their interfaces, export the boundary to STEP, and solve an elasticity problem on a field derived from the volume geometry.

For the desktop workflow start with Edit a bracket from the compact ribbon. For an installed FieldCraft client see Run a native analysis and inspect it in FieldCraft.
