    pub lift: Lift,
    pub leaf_blocks: BTreeMap<LeafKey, String>,

Fields§

§space: AnalysisSpace

Unconstrained Q2 finite-element space with only exact trace identities merged. Hanging coefficients remain present in this space.

§lift: Lift

Exact affine representation of every DOF using the independent masters.

§leaf_blocks: BTreeMap<LeafKey, String>

Stable child-block identity by dyadic leaf.

§constraints: Vec<(usize, Row)>

Canonical exact hanging-node equations after same-level/identity merges.

§boundary_patches: BTreeMap<String, Vec<LeafSide>>

Semantic boundary feature to the originating root sides and leaves.

§root_ndof: usize
