# S3 named lip offset rail: pre-registered design

## Frozen scope and source

This experiment starts from the named `src0` top-lip span documented in
`s3-native-edge-feasibility.md`: block
`s3_i_u_zbase_g2_s0_p0_z2_src0`, source parameter `t in [0,1]`, face
`v=1,w=1`, setback/radius `1/4 mm`. The exact homogeneous source polynomials
are those in the feasibility note. This is one planar contact rail only; it
does not modify a volume chart, add a logical volume, or claim an S3-wide
fillet/chamfer.

## Proposed construction and certification

The initial dyadic linear Bezier prototype required thousands of segments. A
degree-7 experiment reduced that count, but exceeded the native map/export
degree limit. The final rail uses degree-3 polynomial Bezier spans (unit
rational weights) with endpoint positions and first derivatives. The physical
offset remains `0.25 mm`; the accepted rail error is at most `0.001 mm` (one
micron).

For each candidate geometric span, interval Taylor jets enclose the fourth
derivative of the exact offset curve. The certificate subdivides only its
integration domain into 16 intervals (and further if an interval cannot prove
positive speed/weight); this subdivision does not add rail spans. The cubic
Hermite remainder is `sup |R^(4)| h^4 / 384`. Stored control-coefficient error
is computed from the interval enclosures of the ideal Hermite controls and the
actual f64 controls. JSON uses 17-digit scientific notation, which round-trips
the stored f64 controls exactly; that zero serialization error is recorded in
the artifact. The published segments share bit-identical endpoints and
provide C0 continuity. The terminal offset endpoint is exact rational; the
initial endpoint is irrational and its coefficient discrepancy is included
in the measured control error.

## Replay and exit criteria

The example writes a deterministic JSON artifact containing source identity,
radius, side, dyadic intervals, homogeneous controls, per-span bound, and total
bound. Tests replay the artifact, check endpoint sharing, positive weights,
continuity, and every certified bound. A separate test checks the exact source
polynomial and refusal paths. Exit is limited to a bounded rail construction
for this named edge; chart Jacobians, adjacent-face maps, corner closure, and
whole-part treatment remain open.

## Results

The implementation emits both signed rails as degree-3 homogeneous spans with
unit weights. The deterministic replay command is:

```sh
cargo run --example s3_offset_rail -- both build/s3-offset-rail.json
cargo test --lib s3_offset_rail
cargo test --test s3_offset_rail
```

The final replay emits 11 spans per side across the complete source parameter
interval. Maximum certified physical-error bounds are `0.00081366404 mm` and
`0.00078489574 mm`, below the one-micron target. Maximum control-coefficient
error bounds are `1.04e-11 mm`. At `t=1`, the horizontal tangent gives exact
endpoints `(75,34.25) mm` and `(75,33.75) mm`; the `t=0` contact points involve
an irrational normal. The JSON contains the actual control polygons and
per-span bounds and can be regenerated by the example.

An independent evaluator using the source polynomials and analytic unit normal
checked 704 interior points (32 per span). Its largest observed deviation
was `0.00013452270 mm`, below the certified bounds. This sampling is a
consistency check; the stated bound comes from the interval fourth-derivative
Hermite certificate, not the sample count. The earlier linear trial emitted
3,497 spans under a stricter `1e-6 mm` target, and the degree-7 trial emitted
31 per side but was incompatible with current native degree limits. The final
cubic rail uses 11 spans per side and meets the specified `1e-3 mm` target.

This qualifies only the one-dimensional contact-rail approximation. It does
not supply a fillet/chamfer surface, updated adjacent faces or interfaces,
positive volume-chart Jacobians, corner closure, or an all-edge S3 operation.

For the vector-valued Hermite remainder at a fixed parameter, project onto
the unit direction of the error there. Scalar Hermite interpolation commutes
with this fixed projection. The projected fourth derivative is bounded by
the supremum of the pointwise Euclidean derivative norm on the span, which
justifies taking the maximum of the interval subdomain norm bounds.
