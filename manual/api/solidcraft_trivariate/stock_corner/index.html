Module stock_corner 

Source
Expand description

Geometric eligibility and verification for a local treatment of a stock corner.

The module is independent of any CAD host. It recognizes a straight, full-span edge at a convex corner between perpendicular planar supports, derives a right-handed local frame, detects nearby trims on the two supporting planes, and bounds the removed volume.
