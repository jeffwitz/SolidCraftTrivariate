Exact one-level truncated hierarchical B-splines on the recovered strip.

The pilot keeps the geometry parent separate from the field basis. It uses a uniformly prepared tricubic tensor space, then one strictly interior dyadic refinement region. It is a THB basis, not a T-spline construction.
