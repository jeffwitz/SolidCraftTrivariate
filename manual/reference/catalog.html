Command and recipe catalogue

The catalogue is generated from the compiled kernel. Each family has a downloadable JSON recipe. The audit checks family-specific requirements after parsing, including consistency between the source recipe, maps and topology.

Command reference

annulus-edges LAYOUT PROFILE OUT

Emit the knots and homogeneous volume nets for an annulus layout and edge profile.

assemble-patches MODEL LAYOUT OUTPUT

Apply a supplied layout to the source cells and assemble compatible homogeneous control nets.

audit MODEL

Read the persisted model and repeat its family-specific checks on controls, incidence and geometry.

audit-inherited-space PACKAGE

Recheck the saved inherited-space package and its constraints.

audit-parent-field MODEL FIELD

Check the serialized parent field against its geometric model.

build RECIPE OUTPUT

Construct a versioned rational volume model from its family-specific recipe.

capabilities

List the registered construction families, commands and evaluators for this binary.

certify-map MAP MAX_LEAVES MAX_DEPTH

Bound the determinant on the parameter cube under the leaf and depth budgets. Inspect the returned status and lower bound.

check-parent-galerkin MODEL ORDER

Compare the fine and transferred parent stiffness at the same quadrature order.

check-thb-galerkin PACKAGE ORDER

Compare coarse stiffness with the transferred refined stiffness at identical quadrature.

classify-transverse-transitions MODEL OUTPUT

Examine first jets on interfaces and report the supported constant or affine transverse relations.

compose-axial JOB OUT

Subtract a third axial operand from a connected two-operand union, carrying surviving source maps and face ownership.

conforming-bending MODEL NV NW QUADRATURE C0|C1 OUTPUT

Solve the recorded 22-chart fitted S2 elasticity control with the selected refinement, Gauss order and C0 or interior C1 field continuity.

cover-cylinder MODEL 2|3 OUT

Assemble a two- or three-volume cover of the tall three-layer cylinder, including its seam incidence.

crossed-bending MODEL NV NW QUADRATURE OUTPUT

Solve the ten-chart crossed-tool bending study using the specified transverse and thickness subdivisions and Gauss order.

crossed-boolean RECIPE OP OUTPUT

Select an operation in the supported crossed-tool arrangement. The output retains its partial-face footprints.

differentiate-job MODEL JOB DIRECTION OUTPUT

Differentiate an admitted job along the prescribed direction within one fixed regime.

edit-bore-intervals MODEL EDITS OUTPUT

Apply a set of axial bore edits to the saved model with the family’s edit and lineage checks.

edit-fieldcraft-bore-rims MODEL STATE OUTPUT.json|OUTPUT.step

Apply the requested edge state to the qualified FieldCraft bore rims.

edit-s3-stock-rim MODEL sharp|chamfer|fillet OUTPUT.json|OUTPUT.step

Apply the supported stock-rim treatment on the S3 plate and emit its JSON or STEP representation.

evaluate MAP U V W

Evaluate a homogeneous rational map at the three supplied parameters.

export-adaptive MODEL PLAN GAUSS_ORDER OUTPUT

Compile the local refinement plan into an adaptive analysis package and trace constraints.

export-analysis MODEL GAUSS_ORDER OUTPUT

Construct the family’s analysis package with the specified Gauss order.

export-field-vtu RESULT SUBDIVISIONS OUTPUT

Sample the field from a supported result package for VTK visualization.

export-geometry-vtu MODEL SUBDIVISIONS OUTPUT

Sample the geometry at the requested subdivision count for a VTK viewer.

export-inherited-space MODEL PLAN OUT

Apply the requested continuity plan and serialize the constrained field.

export-nurbs-space MODEL OUTPUT

Export the supported conforming rational field with shared trace numbering.

export-parent-field MODEL OUT

Write the extracted canonical field for the recovered strip parent.

export-parent-stiffness MODEL ORDER OUT

Serialize the parent-field stiffness for independent matrix reassembly.

export-sketch-analysis MODEL GAUSS_ORDER OUTPUT

Compile a sketch-derived analysis package at the requested integration order.

export-step MODEL OUTPUT

Write the oriented boundary of an admitted model as STEP for independent CAD readback.

export-thb-extraction PACKAGE OUT

Export element extraction data for the locally refined field.

import-solidcraft SCRIPT OUTPUT

Import a supported SolidCraft script through the historical adapter.

import-solidcraft-sketch TIMELINE OUTPUT

Replay a supported design timeline through sketch and feature constructors.

inspect-travel CENTER_X_UM

Inspect a travelling-bore configuration at the specified centre coordinate in micrometres.

plan-patches MODEL OUTPUT

Select a tensor-patch cover from the existing volume cells and retain the mapping of spans to sources.

plan-sketch RECIPE

Compute the supported arrangement, junctions and construction events before building a solid.

recover-pair-parents MODEL REPORT

Test neighboring cell pairs for a common polynomial parent under the admitted parameter changes.

recover-spline-parent MODEL OUT

Recover the strip’s generating tensor-product parent and verify its restrictions.

recover-translation-columns MODEL AXIS

Find supported chains of translated sections along the chosen axis.

reduce-axial-knots PATCHES OUTPUT

Attempt exact geometry-knot removal on compatible axial chains. Retain source subintervals and selections.

refine-thb-strip MODEL PLAN PACKAGE

Apply the supported hierarchical refinement plan to the recovered strip and save a replayable package.

solve-inherited MODEL JOB OUT

Construct the inherited field from the model and run the supported job.

solve-inherited-space PACKAGE JOB OUT

Solve a supported mechanical job on a persisted inherited field.

solve-job MODEL JOB OUTPUT

Dispatch an elasticity job to the compatible model or saved field space.

solve-parent-field MODEL JOB OUT

Solve an admitted parent-field elasticity job on the recovered strip.

solve-thb-strip PACKAGE prepared|local JOB OUT

Select the prepared or locally refined field from a THB package and solve the job.

spline-eligibility MODEL

Inspect which parent or field constructions the supplied model admits.
