How should I read these values?

Block and interface counts describe the downloadable trivariate model. For the six curved profiles, the minimum block counts apply to layer-aligned partitions with the prescribed arc junctions. The sampled condition number measures map distortion. A lower block count can coincide with higher distortion.

The viewer draws the candidate volume maps. Its sections are visual previews. Each model includes its recipe, audit and STEP export.
