# Preregistration amendment: actual chart partition

This amendment supersedes the initial section of `pocket-lateral-c1-sweep-preregistration.md` before any sweep or focused test was run. The original draft incorrectly described the section as a 3 × 3 Cartesian grid of rectangles. The repository builder instead constructs five quadrilateral section charts below the pocket floor and four repeated outer-ring charts above it. The pocket footprint is itself a quadrilateral chart. Its neighboring interfaces include the four footprint sides and four slanted radial chart edges. Treating the nine cells as rectangles would answer a different question.

The production recipe/model pair in `docs/site/data/plate_blind_pocket/` is also not used as the bilinear benchmark: those maps are not degree-elevated bilinear maps. The benchmark uses the explicit polygonal recipe `tests/references/blind_bilinear_pocket.recipe.json`, which is built and audited by the repository CLI. Its exact 5+4 chart decomposition and interface orientations define the analysis patch complex.

The study assembles a restricted anti-plane Ritz problem on the five distinct section charts. The four outer charts have physical thickness 20 mm; the footprint chart has thickness 14 mm. This is a consistent 3D elasticity subproblem for displacement constant in z, with the manufactured load and natural tractions integrated over the exact blind-pocket geometry. It does not represent unrestricted 3D elasticity. C0 trace identification follows every actual oriented chart interface. The C1 variant adds physical normal-gradient continuity on all eight in-plane interfaces; tangential gradient continuity follows from the common C0 trace. The chart maps' varying Jacobians are retained in stiffness, loads and error norms.

Two implementation failures were detected in the n-refinement smoke run before qualification. The first C1 interface collocation sampled across tangential spline knots; constraints now sample each knot span and are replayed at a denser independent set. The pocket-wall traction quadrature also crossed those knots; it now partitions the line integral by every tangential knot span. The initial invalid measurements and diagnoses are retained in [the failure record](pocket-lateral-c1-sweep-initial-failures.json). They are excluded from the final sweep.

After these fixes, the independent n=1 q12/q16 gate passed the original 1e-9 criterion for three of four p/continuity families. The p=4/C0 state failed with a maximum relative observable change of approximately 1.93e-9. The numerical gate values are retained in the result JSON. Before the sweep, I prospectively selected q16/q24 for every full-run state, retaining the same 1e-9 threshold.

The full q16/q24 sweep passed 13/16 states. The three n=8 failures were p=3/C1 (5.06e-9), p=4/C0 (1.60e-9), and p=4/C1 (1.13e-7). These are retained as failures under the preregistered threshold. One extra diagnostic for p=3/C1/n=8 was attempted at q24/q32 (2.40e-9) and q32/q40 (8.44e-9); neither passed, and further quadrature retries were stopped to avoid accepting accidental agreement between adjacent orders. The failed changes are absolute energy-error delta 3.79e-13 and L2-error delta 4.69e-15 for q16/q24, against relative errors 7.49e-5 and 3.70e-6. The native residual stayed near 3.4e-14, so the failure is not explained by the linear solve residual alone. No threshold was relaxed.

The original wrong draft remains available in the version history of the work session; the corrected protocol and this amendment are the operative preregistration. No case was run under the superseded Cartesian assumption.
