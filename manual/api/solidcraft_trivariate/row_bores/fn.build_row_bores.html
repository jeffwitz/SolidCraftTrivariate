Expand description

Construct a row of n equal-width rectangular macrocells.

Each dimension, center coordinate, and radius is specified in half-mm ticks. centers_ticks[i] and radii_ticks[i] define the bore for band i; order is therefore explicitly left-to-right. The rectangle is [-A,A] × [-B,B] × [0,8] mm and must satisfy A<=80, B<=10 mm.
