Expand description

Build two positive-orientation rational charts for a square corner fillet.

origin and size define the closed square [x,x+size] × [y,y+size]; the removed material is the quarter disk of radius radius at its upper right corner. The output is extruded between z[0] and z[1] in mm. Both circular traces are on v=1. The diagonal trace is exactly shared.
