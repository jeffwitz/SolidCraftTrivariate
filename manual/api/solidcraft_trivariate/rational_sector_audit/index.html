Module rational_sector_audit 

Source
Expand description

An exact certificate for the stored homogeneous nets of a rational angular sector.

At three angular nodes and both radial and axial ends, check all four homogeneous polynomials against the analytic polar chart, up to one positive factor per chart. This tensor grid is unisolvent for degree (2,1,1). The weight is 1+s², the polar angle is 2 atan(s), and radius decreases linearly. These identities on the closed cube establish an inverse and show that distinct chart interiors have disjoint angular intervals.
