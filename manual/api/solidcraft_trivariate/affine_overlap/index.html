Exact pairwise relation checks for integer affine parallelepipeds.

Vertices use the tensor bit order v0 + u*e0 + v*e1 + w*e2 with index u + 2*v + 4*w. Coordinates are integer micrometres bounded to one metre. This module handles only pair relations and declared whole-feature contact; it does not prove global coverage of a multi-block complex.
