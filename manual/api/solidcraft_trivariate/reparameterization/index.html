Module reparameterization 

Source
Expand description

Constrained C1 reparameterization for two adjacent unit-width bricks.

The map on brick i is x_i(u)=i+u+a_i*u*(1-u). The equality a_0+a_1=0 matches the interface speed, while |a_i|<=3/4 keeps the derivative bounded below by 1/4. For fixed data weights and regularizer, the exact L2 objective reduces to a scalar strictly convex quadratic except when both data and regularization vanish.
