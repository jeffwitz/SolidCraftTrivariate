Module spatial_certificate 

Source
Expand description

Outward-rounded Bernstein certificate for local regularity of complete rational trivariate Bézier maps on the closed unit cube.

This certifies only the sign of the Jacobian determinant. It does not establish injectivity, boundary compatibility, or partition of a solid.
