Module movable_bore 

Source
Expand description

Movable circular bore in a fixed square plate, with analytic control jets.

Inputs are integer half-millimeter ticks. Homogeneous controls use one common scale (eight times the frozen E1 profile scale) for every block and every parameter value. The returned geometry is a candidate net; no continuous-domain certificate or rounding enclosure is implied.
